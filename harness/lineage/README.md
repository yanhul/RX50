# RX50 Research Lineage

Durable provenance layer for evidence-driven engineering iterations.

## Lifecycle

`OBSERVE -> INVENTORY -> EVIDENCE CHECK -> PROPOSE -> EXECUTE -> TEST -> REVIEW -> PERSIST -> NEXT GENERATION`

Each engineering hypothesis must retain its parent artifact/decision, exact delta, evidence references, test outcome, contradictions, constraints and unresolved claims.

## Safety boundary

The autonomous agent cannot alter governing requirements, safety criteria, evidence hierarchy, contradiction rules, acceptance criteria, or terminal conditions. Safety-critical design changes remain subject to the approval rule in `AGENTS.md`.

No claim is promoted to validated without the required evidence/test existing. Conflicts are recorded rather than silently resolved.
